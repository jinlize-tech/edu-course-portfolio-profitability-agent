# 课程产品组合盈利诊断领域指南

## 业务问题

课程越多不代表越赚钱，低毛利、低满班、复杂教师依赖和高退费的课程可能长期拖累组织。

## 产品解决方案

按课程、班型、校区和客群分析收入、贡献毛利、续费、退费、复杂度和资源占用，制定保留/改造/退出路线。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `course_financials` | 课程财务数据 | 是 | 收入、成本、退款和学期 |
| `course_operations` | 课程运营数据 | 是 | 满班率、续费、教师和资源占用 |
| `student_placement_constraints` | 在读学生安置约束 | 是 | 转课或退出限制 |
| `strategic_priorities` | 战略优先级 | 否 | 长期价值或课程链目标 |
| `decision_weights` | 决策权重 | 是 | 输出前由用户确认，不得模型自定 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

课程数据口径需统一；不能牺牲教育承诺或在读学生权益；最终决策由负责人承担。
